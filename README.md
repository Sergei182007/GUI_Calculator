# Калькулятор (MVC + Tkinter + собственный лексер)

Десктопный калькулятор на Python с тёмным графическим интерфейсом, реализованный по архитектурному паттерну **MVC (Model–View–Controller)**. Разбор математических выражений выполняется вручную через лексический анализатор и парсер методом рекурсивного спуска (без использования `eval()` и `ast`).

## Функционал

- **Удобный кнопочный интерфейс и поддержка клавиатуры**:
  - отсутствует ручное текстовое поле ввода — выражение собирается строго через кнопки или разрешённые клавиши (`0–9`, `+`, `-`, `*`, `/`, `(`, `)`, `.`, `Enter`/`=`, `BackSpace`, `Esc`/`C`, `R` для `√`);
  - плоские кнопки с подсветкой при наведении и визуальным откликом при нажатии;
  - двухстрочный дисплей (история/ошибка и текущее значение).
- **Операции**: сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`), скобки `(...)`, квадратный корень (`√`).
- **Собственный разбор на лексемы**:
  - `Lexer` разбивает строку на токены (`NUMBER`, `PLUS`, `MINUS`, `MUL`, `DIV`, `SQRT`, `LPAREN`, `RPAREN`);
  - `RecursiveDescentParser` вычисляет выражение с учётом приоритета операций, унарных знаков (`-5`), корня (`√16`, `2+√9`) и вложенных скобок.
- **Валидация и обработка исключительных ситуаций**:
  - пустой ввод, лишние десятичные точки, незакрытые/лишние скобки;
  - деление на `0`;
  - извлечение квадратного корня из отрицательного числа.

## Структура проекта

```text
├── model.py       # Модель: Token, Lexer, RecursiveDescentParser, CalculatorModel
├── view.py        # Представление: тёмный UI на Tkinter и кастомная кнопка FlatButton
├── controller.py  # Контроллер: управление состоянием ввода и связь Model с View
└── README.md      # Документация проекта
```

## Установка и запуск

### Требования

- Python 3.8 или выше (внешние зависимости не требуются)
- Установленный `tkinter` (на Windows/macOS идёт в комплекте с Python; на Ubuntu/Debian при необходимости: `sudo apt install python3-tk`)

### Пошаговая инструкция

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <URL_вашего_репозитория>
cd <папка_проекта>
```

2. Запустите приложение:

**Linux / macOS:**

```bash
python3 controller.py
```

**Windows:**

```cmd
python controller.py
```
